How to use

📄 PDF → Image
  1. Open PDF (or drag & drop it onto the window).
  2. Navigate pages (◀ ▶), zoom (− / + / Fit) — display zoom never affects output quality.
  3. Drag on the page to select a region. Move it by dragging inside; resize with the corner handles.
  4. Pick the output DPI (300 for print), then Save Selection or Save Full Page. The PNG is rendered at full DPI with real DPI metadata embedded.
  5. Or choose a target panel and hit ➜ Composer to send the crop straight into the Figure Composer.
🧩 Figure Composer
  1. Set the number of panels (1–10), padding, canvas size and background.
  2. Load image(s) — multiple files fill panels in order. Double-clicking an empty panel also opens the file picker. Supports PNG, JPG, BMP, WebP, GIF and TIFF.
  3. Move / zoom mode: drag the image inside its panel; mouse wheel zooms.
  4. Draw ROI mode: drag a green box, then ✂ Apply ROI crop. Undo crop restores the full image.
  5. Adjust brightness / contrast / saturation / sharpness per panel.
  6. Enable a scale bar (length, thickness, text, font, color, position) — Copy to all panels keeps them consistent.
  7. Pick a panel label style (a b c / A B C / 1 2 3).
  8. 💾 Export figure PNG (with DPI tag) or 📋 Copy to clipboard.

Tip: use Chrome or Edge — saving then offers a proper Save-As dialog so you can pick the file name and location.
